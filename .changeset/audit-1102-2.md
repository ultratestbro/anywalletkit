`signBuilt`, `signTransaction`, `sendTransaction` and `transfer` now take one plain copy of the transaction (encoded to borsh and decoded back) before the hard checks, and sign exactly that copy. A transaction object that changes between reads — a getter on `actions`, or an `actions` array the caller edits while the account waits for the node — can no longer get a different transaction signed from the one that was checked. `signBuilt` returns the copy as `transaction`; its bytes are the same as before for every ordinary transaction, so nothing changes for apps.
