`describeProtocolBehaviour` now checks TRC-20 `approve` / `increaseAllowance` calldata inside a Tron call the same way it checks approvals on EVM. The spender must be declared (`spender`, `callTargets` or the source token), the allowance must be below the unlimited threshold and no more than the input, and the arguments must be readable. Before, a Tron call to the declared source token that approved an undeclared spender for the maximum passed the suite. Module authors whose Tron fixtures approve inside the source call must declare that spender and approve exactly the input.
