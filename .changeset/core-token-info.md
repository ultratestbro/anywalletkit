Token info: `TokenInfo` / `TokenFlag` types, an optional `getTokenInfo(token)` on read-only accounts (decimals, symbol, name, supply and holder-relevant flags read from the chain) and `NotATokenError` for an address that is not a token. `Swap2Options.fromTokenDecimals` carries the decimals of a source token outside the swap catalog.
