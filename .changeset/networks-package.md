New package `@forgewallet/networks`: one table of networks for every wallet build. The catalog mainnets (30 EVM chains plus Solana, TON, Tron, Bitcoin, NEAR, Zcash) with the public RPC failover lists the mobile app and the extension used to keep separately; default testnets for every family (Sepolia, Base / Arbitrum / OP Sepolia, Polygon Amoy, BSC testnet, Monad testnet, Solana devnet, Bitcoin testnet4, TON testnet, Tron Nile, NEAR testnet, Zcash testnet), shipped disabled; `NetworksTable` over any `JsonStorage` (AsyncStorage, chrome.storage, memory) — user RPCs are prepended to a builtin list, builtins cannot be deleted, `onlyOwnRpc` drops the public fallback, custom networks have none, a user RPC whose check failed is parked with the reason; `verifyNetwork` per family (EVM `eth_chainId`, Solana `getGenesisHash`, TON config param 19 global id, Tron genesis block id, BTC / Zcash genesis over Esplora / Blockbook / Blockchair, NEAR `status.chain_id`) with latency and tip; the URL policy (https only, `http://` for private addresses behind the explicit opt-in); `parseAddChainParams` (EIP-3085) lifted from the extension kit with the site origin recorded as the network's source.
