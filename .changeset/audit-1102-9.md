An HTTP error page (a gateway's 5xx without a JSON-RPC body) that happens to contain "already known" is no longer reported as a successful send: it now ends as `BroadcastUnknownError` (`maybeSent: true`), like any other HTTP failure. A node's JSON-RPC "already known" answer is still accepted, on any HTTP status and from any endpoint of a provider list.
