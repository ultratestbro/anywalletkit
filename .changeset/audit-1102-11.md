The fee-rate check on caller-set fees now waits at most `FEE_QUOTE_TIMEOUT_MS` (5 seconds, exported) for the network's fee quote. If the RPC does not answer in time the check is skipped, as it already was for an unreadable quote, so `signTransaction` of a fully specified transaction no longer hangs on a provider that never answers. Note that with a provider configured, signing a transaction with caller-set fees makes two read calls (`eth_gasPrice` and the latest block) for this check.
