# Module registry

`modules.json` is generated by `pnpm registry` from every `packages/*/module.json`
plus `external.json` (modules that live in their own repositories). Do not edit it
by hand.

A manifest:

```json
{
  "name": "@scope/protocol-staking-foo-evm",
  "type": "staking",
  "chains": ["eip155:1"],
  "tier": "community",
  "maintainers": ["@you"],
  "conformance": "0.x",
  "repo": "https://github.com/you/protocol-staking-foo-evm",
  "addedAt": "2026-10-04"
}
```

Tiers: `community` (conformance passes) → `verified` (review + one live transaction
linked in the PR) → `core` (maintained by the project). A module whose maintainer is
unresponsive for 6 months is marked `deprecated`; nothing is ever silently removed.
To list an external module, add it to `external.json` in a PR that links its
conformance run.
